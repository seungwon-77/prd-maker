| 질문 | 답 |

| 칸 | 고른 것 | 안 고른 후보 |
|---|---|---|

### DESIGN.md 8번 (반영 완료)

- 프리셋: C. 페이퍼
- `--accent`: `#c2410c` 대신 `#0f766e`(딥 틸). 핫핑크는 빼라고 해서 Claude가 고른 색이다. 바꾸고 싶으면 DESIGN.md에서 한 줄만 고치면 된다.

## 리스크 (구현할 때 신경 쓸 것)

- **범위가 커질 수 있다.** 8-2(풀스택 PM)와 8-3(단계별 구현 순서) 둘 다 범위를 넓히는 쪽이라 이걸 잡아 줄 장치가 없다. 시스템 프롬프트에 "P0는 3개까지" 같은 제한을 넣는다.
- **생성이 30초를 넘길 수 있다.** 8-3 섹션 때문에 출력이 길어진다. 넘기면 "Step은 최대 5개"처럼 개수를 제한한다.
- **8-4가 기존 기능과 겹친다.** `.md` 다운로드는 P1 "마크다운 복사"와 거의 같은 기능이다. 같은 마크다운 변환 함수를 재사용하면 된다.
